# 📈 반응속도 테스트 웹사이트

![반응속도 저작권 배너](https://taejun09.github.io/taejun-storage/img/%E1%84%8C%E1%85%A60%E1%84%8B%E1%85%B2%E1%84%92%E1%85%A7%E1%86%BC_%E1%84%92%E1%85%A1%E1%86%AB%E1%84%80%E1%85%B3%E1%86%AF.png)

> 웹 브라우저에서 사용자의 반응속도를 측정하고 기록할 수 있는 오픈소스 프로젝트  
> 간단한 게임처럼 즐기면서 자신의 반응속도를 확인하고, 랭킹과 히스토리 그래프로 성과를 확인할 수 있습니다.



## 🔹 주요 기능
- 평균, 최소, 최대 반응속도 계산  
- 클릭 반응 기반 랭킹 보드 제공  
- 반응속도 히스토리 그래프 시각화  
- 모바일 및 PC 환경 모두 지원  
- 사용자 등록 및 기록 저장 (LocalStorage 사용)  



## ⚡ 사용 기술 및 라이선스
- HTML / CSS / JavaScript
- [Tailwind CSS](https://github.com/tailwindlabs/tailwindcss/blob/master/LICENSE)  
- [Chart.js](https://github.com/chartjs/Chart.js?tab=MIT-1-ov-file)
- [Tossface](https://github.com/toss/tossface/blob/main/LICENSE)  
- [이서윤체](https://noonnu.cc/font_page/872)



## 💻 설치 및 실행
- 웹 브라우저에서 index.html 열기
- 별도의 서버 없이 로컬 브라우저에서 바로 실행 가능



## 🖱️ 사용 방법

- 닉네임 입력 후 게임 시작 클릭
- 화면이 빨간색일 때 기다리기
- 화면이 초록색으로 바뀌면 클릭!
- 반응속도 기록이 표시되고, 총 5회 반복 후 평균 반응속도 확인
- 랭킹 보드에서 내 기록과 다른 유저 기록 확인 가능
